# Changelog

## 0.1.0 — 2026-11-25
First release.
- Encrypted work log: quick-add (`Ctrl+Alt+L`) that works while locked, ⭐ highlights, #tags, auto project/branch.
- Dashboard: streak, monthly highlights, 18-week heatmap, searchable animated timeline.
- Year in Review with a configurable appraisal year, and Markdown export for appraisals.
- Standup drafter for Teams (log + git fallback, Monday covers Friday, yesterday's plan shown).
- Break Buddy: eyes/stretch/water reminders on active coding time, notification or full break screen, focus mode,
  working hours, all timings adjustable.
- Tamper protection for edits/deletes, key rotation on password change, multi-window safety, encrypted auto-backup,
  merge import.
